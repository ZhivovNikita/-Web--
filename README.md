## Тематика сайта, название

Веб-приложение "Тренажёр скорости печати". 
Идея реализовать инструмент для развития навыка слепой печати и увеличения скорости набора текста без установки дополнительного ПО

## Цель и задачи сайта

Повышение эффективности работы с текстом у пользователей за счет тренировки скорости и точности набора
 
 Предоставить пользователю интерфейс для набора текста в реальном времени.
 Визуализировать ошибки и прогресс с помощью цветовой подсветки.
 Рассчитывать ключевые метрики: скорость знаков в минуту и точность
 Мотивировать на повторное прохождение через отображение результатов

## Целевая аудитория

Студенты и школьники, программисты и копирайтеры

## Содержание сайта

* Блок статистики
* Игровое поле
* Поле ввода
* Экран результатов

## Функциональные возможности

* Генерация текста
* Подсветка синтаксиса набора
* Расчет метрик в реальном времени
* Защита от читерства
* Автоматический старт
* Адаптивность
